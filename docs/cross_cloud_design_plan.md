## 关键设计问题清单

设计过程中需要明确的**核心问题**：

### 数据层
- [ ] 用户余额是否允许秒级不一致？
- [ ] 房间在线人数是否跨云同步？
- [ ] 聊天记录如何归档？

### 服务层
- [ ] WebSocket消息是否持久化？
- [ ] 全站礼物广播的延迟要求？
- [ ] RTC房间ID是否与WebSocket房间ID一致？

### 故障切换
- [ ] 自动切换还是人工确认？（初期建议人工）
- [ ] 故障切换时正在进行的礼物交易如何处理？
- [ ] 房间迁移后，原房间的麦位状态是否保留？

### 客户端
- [ ] 断连后多久开始重试？
- [ ] 房间迁移时用户是否需要确认？
- [ ] 弱网环境下的降级策略？
